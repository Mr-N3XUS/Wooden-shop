### 🎯 About The Project

> **Wooden Shop** is an elegant and minimalist online store for handmade wooden products. Crafted with HTML, CSS, and JavaScript – it offers a clean, aesthetic browsing experience for lovers of natural wood art.

### ✨ Features

| 🪑 Product Showcase | 🎨 Aesthetic Design | 🛒 Interactive Shopping |
|:-------------------:|:-------------------:|:-----------------------:|
| Beautiful display of wooden items | Warm, natural color palette | Smooth cart interactions |

| 📦 Product Categories | 🖱️ Smooth Animations | ⚡ Lightweight & Fast |
|:--------------------:|:--------------------:|:--------------------:|
| Furniture, decor & accessories | CSS transitions & effects | No frameworks needed |

### 🛠️ Technologies Used

| Technology | Purpose |
|:----------:|:-------:|
| **HTML5** | Structure & content |
| **CSS3** | Styling, animations, responsive design |
| **JavaScript** | Interactive elements & cart logic |
